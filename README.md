# 웹 포트폴리오 프로토타입

직접 작업한 웹 프로젝트 6개를 소개하는 반응형 포트폴리오입니다.

## 실행

Node.js 설치 후 `npm start`를 실행하고 http://127.0.0.1:4173 에 접속합니다. 별도 패키지 설치는 필요하지 않습니다.

## 구성

- 실제 사이트 화면을 활용한 프로젝트 미리보기
- 프로젝트 상세 모달과 외부 사이트 링크
- 모바일 레이아웃, 키보드 탐색, 모션 감소 설정 지원
- `index.html`, `style.css`, `app.js`: 페이지 구조, 스타일, 인터랙션
- `assets/`: 실제 사이트 화면 캡처

정적 웹 호스팅에 루트 폴더를 배포할 수 있습니다. Google Fonts는 인터넷 연결이 필요하며, 연결할 수 없으면 시스템 글꼴을 사용합니다.

## 제출 전 확인

이름과 소개 문구는 시안입니다. Apps Script 프로젝트 A/B의 이름과 설명을 실제 내용으로 수정하고, 프로젝트 B의 `/dev` 링크를 공개 배포 주소로 교체하세요. 캡처 화면은 실제 사이트의 최신 상태와 다를 수 있습니다.
